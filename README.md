# Лабораторная работа №2

**Тема:** TCP-сервер и обработка сетевых подключений.

Программа написана на языке C для Linux.

Сервер работает на порту 8080, принимает подключения клиентов и выводит количество полученных байтов. Одновременно сохраняется только одно клиентское соединение, остальные закрываются.

## Компиляция

```bash
gcc main.c -o lab2
```

## Запуск

```bash
./lab2
```

Для подключения к серверу из другого терминала:

```bash
nc 127.0.0.1 8080
```

После подключения можно отправлять сообщения. Сервер выводит количество полученных байтов.
